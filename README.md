# 交大总控（公开说明版）

个人学习工具的一页总控：**交大一日**、**AI 前沿**、知识站、Obsidian 可视化、**四年指南**、DeepSeek Harness 等入口的聚合界面。

## 重要说明

- **本公开仓库不连接作者电脑上的任何服务**，GitHub Pages 上仅为静态界面与示例数据，不能用来遥控或访问作者本机。
- 绿点、真实跳转与资讯预览只在**你自己本机**部署 `server.mjs` 并启动对应子服务后才会出现。
- 原件中的桌面快捷方式脚本、DSH 绝对路径与本机私有目录启动逻辑**未纳入**公开版。

## 在线查看（静态）

GitHub Pages 展示页面布局与模块说明，数据来自 `data/sites.demo.json`。

## 本地运行

```powershell
node server.mjs
# 浏览器打开 http://127.0.0.1:8330/
```

或双击 `start.bat` / `start.ps1`（仅启动本仓库内的总控服务）。

子项目路径与端口需自行配置；`server.mjs` 内的端口列表仅为**示例**，不代表作者公网可访问的入口。
